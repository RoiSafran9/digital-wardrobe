# KIPS — מדריך התקנה ובדיקה ל־5 החברים הראשונים

זוהי גרסת בדיקה באייפון. היא עדיין לא זמינה להתקנה רגילה מה־App Store. אין רכישות בתוך האפליקציה בבטא המתוכננת. העיבוד פועל על שרת בטא קטן ולכן לעיתים השירות עשוי להיות לא זמין; במקרה כזה, פשוט מדווחים למי שהזמין אתכם.

## לפני שמתחילים

- אייפון תואם וחשבון Apple פעיל להורדת אפליקציות.
- כתובת מייל נגישה לקבלת קוד התחברות בן 6 ספרות.
- שלושה בגדים שהיית רוצה לראות בארון דיגיטלי. אפשר להניח אותם על מיטה או רצפה באור טוב.
- חיבור לאינטרנט; עבור הבדיקה עדיף רשת סלולרית או Wi-Fi רגיל, לא המחשב של המפתח.

## התקנה בארבעה צעדים

1. באייפון, פתח/י את TestFlight הרשמי של Apple והתקן/י: https://apps.apple.com/us/app/testflight/id899247664
2. באייפון, פתח/י את **קישור ההזמנה ל־KIPS**: {{KIPS_TESTFLIGHT_LINK}}. אם קיבלת הזמנה אישית במייל, פתח/י את הודעת ההזמנה של Apple במקום זאת.
3. ב־TestFlight לחצ/י **Accept** (אם מוצג), ואז **Install** ליד KIPS. המתן/י לסיום ההתקנה ולחצ/י **Open**.
4. בתוך KIPS היכנס/י עם המייל שלך וקוד שש ספרות שנשלח אליו. זו התחברות נפרדת מחשבון Apple שמותקן עליו TestFlight.

## מה לנסות קודם — בלי להעלות את כל הארון

1. התחל/י ב־3 בגדים בלבד (מומלץ חולצה + מכנסיים + פריט נוסף, כדי שיהיו סוגים שונים).
2. אפשר לצלם כמה בגדים יחד או תמונות נפרדות. ההוראות בתוך האפליקציה יכוונו אותך.
3. אחרי הזיהוי בחר/י את הפריטים שברצונך ליצור, ואשר/י את הפעולה אם מוצג מסך קרדיטים.
4. אחרי העיבוד, פתח/י את Closet ובדוק/י שהתמונה באמת דומה לבגד שלך — צבע, גזרה, הדפס ופרטים.
5. אם מתחשק לך, נסה/י **Build My Look** עם הבגדים הקיימים. לוק מלא יופיע רק אם יש פריטים מסוגים מתאימים.

**לא צריך לצלם את כל הארון.** אנחנו בודקים אם ההתחלה ברורה ואם שווה לך להמשיך.
