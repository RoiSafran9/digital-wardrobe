# KIPS launch film (V16)

Remotion project for the KIPS launch film. Story, scene timings, data sources, music and the rules the cut
follows: [FILM.md](FILM.md).

- Preview: `npm run dev`
- Render: `npx remotion render KipsLaunchV16 out/kips-launch-v16.mp4`
- Check: `npm run lint`

Garment images, photos and the music file are not committed; `FILM.md` says how to fetch them.
